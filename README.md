# NVIDIA B300 Blackwell Ultra - Slide Decks

A web-based presentation site for the NVIDIA B300 Blackwell Ultra technical deep dive, built with Reveal.js. Hosted as a static site via GitHub Pages.

## Features

- **Two Slide Decks:**
  - **Video 1: Technical Deep Dive** -- Architecture, tensor cores, NVFP4 precision, memory, multi-GPU scaling, and performance benchmarks
  - **Video 2: Should You Switch to B300?** -- Use cases, cloud GPU economics, software stack, and key takeaways
- **Dark-Themed NVIDIA Design** -- Custom CSS with NVIDIA green accent styling
- **Responsive Layout** -- Works on desktop and mobile browsers
- **Reveal.js Presentations** -- Interactive slide navigation with animations

## Tech Stack

- **Presentation Framework:** Reveal.js 5.1.0 (CDN)
- **Frontend:** HTML, CSS
- **Hosting:** GitHub Pages (static site with `.nojekyll`)

## Setup / Installation

No build step required. Simply clone and open in a browser:

```bash
git clone https://github.com/bnarasimha21/nvidia-b300-slides.git
cd nvidia-b300-slides
open index.html
```

Or visit the GitHub Pages deployment directly.

## Usage

- Open `index.html` for the landing page with links to both slide decks
- Navigate slides using arrow keys or on-screen controls
- Press `F` for fullscreen, `O` for slide overview
